# Lung Cancer Disease Prediction System

## Project Overview
The Lung Cancer Disease Prediction System is a web-based application designed to predict lung cancer risk using Machine Learning. It provides users with a simple interface to enter relevant information and view prediction results.

## Technologies Used
- React.js
- TypeScript
- Python
- Machine Learning
- Logistic Regression
- HTML
- CSS

## Key Features
- User-friendly dashboard.
- User login interface.
- Lung cancer risk prediction.
- Machine Learning-based prediction using Logistic Regression.
- Results visualization through a dashboard.

## Project Workflow

1. User accesses the application.
2. User enters the required information.
3. Input data is processed by the prediction system.
4. Logistic Regression model generates a prediction.
5. Results are displayed through the dashboard.

## Project Objective
To develop a web-based machine learning application that demonstrates lung cancer risk prediction and presents results through an interactive dashboard.

## Note
This project is developed for educational purposes and is not intended to replace professional medical diagnosis.

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
